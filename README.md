# OpenBumpkins

Decompilation and C reimplementation of Beasts & Bumpkins (with [bb-patch](https://github.com/bb-patch/bb-patch) applied).
The work was performed using *GPT-6.1-Sol* at *xhigh* effort. 
Source and any binaries are provided as-is. 
At the time of writing, the game seems to be fully playable until at least scenario 8.

## Beasts & Bumpkins

I used to play this game way back when, and I come back to it every couple of years. 
To make sure I can keep playing it in the future, I did the most 2026 thing possible: Have GPT6 reimplement it, so I can play it without having to deal with compatibility issues.
I hope others will find this useful as well.

## Platforms

Windows - No build currently, use bb-patch
Linux - tested, playable
MacOS - tested, playable

## Scope

For the time being, and probably forever, the purpose of this project is only to provide a workable base to play the game on modern platforms. Minor QoL features may be added.
Much of the C code is not much clearer than the disassembly. Any attempts to clean and clear it up are not currently within the scope of this project.
